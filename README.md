# dsh-skill-easy · 技能分类与中文描述

把 DSH 的技能（skill）管起来：分类、写中文描述、用你自己配置的大模型批量翻译。装好后输入框打 `/`，技能不再是糊成一片的英文列表，而是按你分的组分段显示，描述是中文。

## 安装

需要 DSH `0.2.1-rc.3` 或更高版本。

**让 AI 装**：在 DSH 里说「装 dsh-skill-easy 这个插件」，走插件市场。

**手动装**：把仓库放到本地，在「设置 → 插件」里从本地目录安装。

装完**重启 DSH** 才生效。

## 它做什么

- **分类**：在「设置 → 技能分类」建分组（写作、审查、部署……），拖动手柄排序；分类顺序就是 `/` 菜单顺序，没归类的排最后。
- **归组**：每条技能右侧下拉选分组，或直接把技能**拖到别的组**；组内拖动调整顺序。
- **中文描述**：每行直接填中文，留空显示英文原文。
- **用你的大模型翻译**：工具条选翻译模型（宿主里已配置的所有模型），点「一键翻译」只翻「未翻译 / 原文已变」的条目，**不覆盖你手改过的**。原文与译文并排可对照、可单条重翻。
- **批量**：点「选择」进入批量模式，可批量归组 / 翻译 / 清除中文 / 隐藏。
- **隐藏**：把不用的技能从 `/` 菜单里藏掉（设置页仍可见，随时恢复；**不是**真禁用）。
- **详情**：点技能名展开，看原文、路径、来源、是否模型可调用、使用时机。

## 翻译怎么工作

调用宿主 `ctx.llm`（你已在 DSH 里配好的大模型路由），插件本身不碰 API key。多条描述合并成一次请求省 token，整批格式出错时自动退回逐条翻译。模型不可用时按钮置灰，手动填写始终可用。

## 数据在哪

`~/.dsh/storages/dsh-skill-easy/data.v2.json`

纯 JSON，可直接备份或手改。**v2 使用独立文件，不读旧的 `data.json`**（旧文件原样保留，升级后从空白开始，需要你重新建分组、重新一键翻译）。

## `/` 菜单与「两份」说明

本插件用公开的 `inputTriggers.registerSource` 注册了一个**属于自己**的 `/` 源（不再猴补官方私有字段）。官方自带的 `技能` 组会保留，所以 `/` 菜单里会同时出现「官方未分组」和「本插件分组」两份技能——这是保官方全套（技能 chip、toolview、引用预览）所付出的代价。

菜单源注册失败（宿主结构变化）时不报错、不影响任何官方功能，设置页会显示「菜单未生效」，分类和中文数据都还在。

## 开发

```bash
npm run check   # 语法检查 + 菜单分段 / 存储保存序列 / 乐观锁回归测试
```

`index.js` 是宿主半边（技能并集读目录 + Remote + `ctx.llm` 翻译），`store.js` 是数据与乐观锁（可单独测试），`client.js` 是浏览器半边（设置页 + 自己的 `/` 源），零构建、无第三方依赖。

## 卸载

在「设置 → 插件」里卸载，或从 profile 移除后重启。数据文件需手动删。
